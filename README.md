# SAT Arena

Bluebook-style Digital SAT practice on official College Board Question Bank questions, with 1v1 matches.

- **Bluebook test window**: section/module header, timer (hide, 5-minute alert), Directions, Highlights & Notes,
  Line Reader, Mark for Review, answer eliminator, question navigator, Check Your Work page, Desmos calculator,
  reference sheet, student-produced response box with answer preview.
- **Practice** (`/practice`): custom sets by domain/skill/difficulty, new-to-me or mistakes-only pools, optional
  timer, check-as-you-go or test mode; Bluebook-style modules (official domain mix and order) and adaptive
  two-module sections. Progress is kept in the browser.
- **1v1 Arena** (`/arena`): invite link, live opponent progress, server-held answers and clock (refresh-safe),
  results by domain and question, rematch, answer review.
- **Shared links**: `/practice?ids=<id>,<id>` opens specific questions (More → Copy Question Link).

## Run locally

```bash
cd backend && npm install && npm start          # http://localhost:3001
cd frontend && npm install && npm run dev       # http://localhost:3000 (set NEXT_PUBLIC_BACKEND_URL=http://localhost:3001)
```

Tests: `cd backend && npm test`.

## Question bank

`backend/data/questions.json` is generated by `backend/tools/build_bank.py` from several cross-checked sources;
see [backend/tools/README.md](backend/tools/README.md). Questions from the official Bluebook practice tests are
excluded unless a player opts in.

All questions, passages and explanations are © College Board. This is an independent study tool, not affiliated
with College Board.
